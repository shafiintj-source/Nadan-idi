# Naadan Adi 3D

Fresh 3D third-person arena-shooter direction for Android.

- Default language: English
- Optional language: Malayalam
- Room target: 2–6 players
- Engine target: Godot 4.x / GDScript
- First milestone: one offline greybox arena with responsive third-person controls

See:
- [Architecture decisions](docs/ARCHITECTURE.md)
- [Build plan and completion gates](docs/BUILD_PLAN.md)
- [Current client status](CLIENT_PROJECT_STATUS.md)

The repository also contains the legacy multiplayer-server/deployment work. It is not yet proven compatible with this fresh 3D client. Treat it as a separate integration task.

**Important:** The fresh branch is a foundation/planning branch, not a release build. No APK/AAB is available from this branch yet.
